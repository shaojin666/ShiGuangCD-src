## 一、Bug 修复：退出演出层后鼠标失效

- **现象**：退出全屏歌词模式后，主界面用快捷键可以操作，但鼠标点不动界面。
- **根因**：`FlStage.close()` 里调用了不存在的 `App.navigate`（`navigate` 是**顶层函数**，不是 `App` 的成员），抛 TypeError 后跳过 closeTimer，透明全屏层留在原地吃掉所有鼠标事件。快捷键不走 DOM 所以仍然有效——这就是"键盘能操作、鼠标失灵"的原因。
- **修复（双保险 + 绝不挡关闭）**：先判 `typeof App.navigate === 'function'`，再回落判 `typeof navigate === 'function'`，两者都包在 try/catch 里——**导航失败绝不影响关闭流程**，closeTimer 无条件执行。
- **回归**：`tests/fl-stage.test.js` 第 9 组 + 真浏览器复现脚本（复现→修复→验证三连）。

## 二、右下角专辑封面 + 弹出光盘

- **右下角竖排容器**（`.fl-bottom-right`）：上方**专辑封面**（`.fl-cover-art`，有封面显图、无封面露占位光盘，`has-cover` 门控），下方播控菜单钮。菜单底边抬高到封面顶沿之上，不挡不叠。
- **封面 URL 收敛到 `coverUrlOf()`**：signature 缺失时不拼坏 URL；`cd:metadata` 事件驱动 `FlCapsule.sync`（**同曲目数/同时长也刷新封面**——以前这种"没变化"的通知会被去重挡掉，封面就丢了）。
- **「弹出光盘」菜单项**：先撤演出层（`forceClose`）再发 `cd:eject`——退碟仪式回主界面正常演出，演出层绝不会盖住读盘仪式。

## 三、全局弹出方式（folia 逐字演出，对所有主题生效）

设置面板「全屏歌词」区新增「**弹出方式**」下拉，演出层面板同步加 chip 三选一（同键 `flReveal`，`dataset.reveal` 是真相源，两边互为出口）：

| 模式 | 行为 |
| --- | --- |
| `all` | 全部显示（既有行为，默认；整段跳过，零成本） |
| `line` | 未唱到的整行不预显，唱到才整行落入 |
| `word` | 未唱的词不预显，唱到才逐字浮现 |

- **架构**：`.fl-line`（定位链）内嵌 `.fl-in`（揭示链）的**双层结构**——弹出动画与主题变换彻底解耦，主题 CSS 永远不用知道弹出方式的存在。
- **无状态状态机**：揭示状态每帧由当前行号 `cur` 推导（`rv-on ⟺ i===cur`、`rv-past ⟺ i<cur`），不引入任何新状态量；词门控只写 `opacity/filter` + `w-on` 类，**不侵占主题的 translate/rotate**。
- **与 whisper 主题的冲突**（实测抓到）：whisper 的入场补间会内联 opacity 压过词门控 → 三件套：`reveal !== 'all'` 时跳过入场、补间 `clearProps: 'opacity'` 善终清残留、dispose `killTweens` + `removeProperty` 管中途切主题。

## 四、两个 3D 运镜主题（歌词在三维空间演出 + 镜头真的在动）

| 主题 | 排布 | 运镜特征 |
| --- | --- | --- |
| **跃迁 Warp** | 行按与当前行的距离（`--ad`）沉入 Z 深处并微微后仰，唱到的行「跃迁」到镜前最大最亮 | 推轨感最强（dolly 44px、鼓点推近 24px） |
| **星环 Halo** | 歌词行排在绕镜头旋转的**圆环**上（按 `--d` 带符号角度差），行面朝环心（=观众），当前行永远在镜面正前方 | 环内穿行感（环绕 3.4° + 升降 16px + 换行切镜） |

### 4.1 CSS 3D 运镜架构（为什么不是 three.js 文字）

- **CJK 字体转 JSON 体积不可行**（一个中文字体几 MB 起），所以两个主题都用 **CSS 3D + JS 运镜 rig**：文字保持系统字体清晰渲染、无下载、无降级链、无 WebGL 依赖。
- **镜头**：`#fl-stage[data-theme=warp/halo] { perspective: 1150px }` 即摄影机镜头。
- **rig 就是 `#fl-lyrics` 自身**（不新增 DOM）：JS 每帧只写一次 `style.transform = rotateX() rotateY() translate3d()`，走合成层不触布局。实测运镜中帧率 ≥30fps（headless 软件渲染）——preserve-3d 文本不会逐帧重栅格化。
- **运镜编排**（`makeCamRig` 共用）：基础正弦环绕 + 升降 crane + 鼓点推近（bass/pulse）+ 指针视差（一阶低通）+ **换行切镜鞭打**（方向交替，GSAP 踢代理对象 1.05s 归位）+ 入场推近。GSAP 仍只做一次性编排，不进逐帧热路径；GSAP 缺失时静默降级。
- **3D 上下文纪律**（实测踩坑）：`opacity<1` / `filter` 会把子树**拍平**（词的 translateZ 全废）→ 两个主题把 `.fl-line` 的 opacity **钉成 1**，距离衰减改由 Z 景深 + 透视 + **字色 alpha**（color 不拍平）承担；窗口剔除仍是 `.fl-out` 的 `opacity:0 !important`（基础规则压过主题）。`.fl-in` 同样要 `preserve-3d`，否则词的 translateZ 全废。
- **圆环几何多项式近似**（Chromium 108 无 CSS `sin()/cos()`，111+ 才有）：`sin θ ≈ θ-θ³/6`、`cos θ-1 ≈ -θ²/2+θ⁴/24`，θ = `--d × 步距角`，|θ|≤45° 误差 <2%，肉眼不可辨；全部走 CSS 变量计算，热路径零逐帧 JS 写入。

### 4.2 与弹出方式联动（逐字演出本身就是 3D 的）

word 模式下未唱的词沉在 Z 深处（Warp **-46px** / Halo **-40px**），唱到才向观众弹出归位——folia 式逐字揭示在三维空间里完成。

### 实测抓到并修掉的坑（都有回归断言）

1. **退出后鼠标失效**（见 §1）：`App.navigate` 不存在 → TypeError 吞掉 closeTimer。
2. **词门控被 whisper 入场压过**：GSAP 补间内联 opacity > 样式表 → 跳过 + clearProps + dispose 清理三件套。
3. **面板 chip 切换后不高亮**：`syncReveal` 只挂在 mount 返回值上，模块级 return 漏加 → `window.FlPanel.syncReveal` undefined；两处都导出（与 `setTheme → syncParams` 同律）。
4. **测试墙钟漂移**：Transport 是墙钟模型，浏览器采样前必须 `paused@<位置>` 冻结，否则真实时间流过位置全漂（verify7 首轮 6 个 FAIL 全是这么来的，实现本身无恙）。
5. **`translate` 计算值序列化**：`translate: 0 0 0` 序列化成 `"0px"`（单值！），解析必须兼容单值与三值两种形态。
6. **`rotate` 序列化带轴名**：`rotate: y -22deg` 序列化成 `"y -22deg"`，`parseFloat` 直接 NaN——先正则取数字。
