# ShiGuangCD v10.9.2 更新说明（收尾轮）

本次是**发布前的收尾轮**：设置面板双栏化、选歌按钮换音乐图标、版本号回到 **1.0.0**。变更共涉及 **5 个文件**（1 个新增 + 4 个修改 + package.json 版本号 + 本说明）。

## 一、设置面板：左分类 + 右内容双栏

- **原问题**：六大组（外观 / 全屏歌词 / 播放 / 系统 / 快捷键 / 关于）纵向罗列，一屏滚不完，找一项设置要翻半天。
- **新布局**：**左侧分类导航（带图标）+ 右侧设置内容**。点左栏分类，右栏切换到对应分组并独立滚动，左栏常驻不消失；默认停在外观。
- **分类与图标**：外观（调色盘）/ 全屏歌词（字幕框）/ 播放（播放钮）/ 系统（齿轮）/ 快捷键（键盘）/ 关于（信息圈）。
- **实现方式（组装层重组，业务零改动）**：所有设置行的构建逻辑**一行未动**——`open()` 里 body 仍然是「`.set-section` 标题 + 行」的顺序结构，构建完成后按 `.set-section` 切分成若干 `.set-page`，套上 `.set-nav` 左导航。**新增一个分类 = 加一个 `section()` + 在 `NAV` 数组登记一行**（键名与标题一致即自动对上），不需要动任何其它代码。
- **不污染通用面板**：双栏样式只作用于设置专用类 `.set-panel`（宽 720px、限高），`.panel-body` 通用规则未改——编辑面板、主题面板等完全不受影响。
- **面板限高**：`height: min(620px, calc(100vh - 120px))`，小窗口自动收缩；右栏 `overflow-y: auto` 独立滚动。

## 二、选歌按钮图标：购物篮 → 音乐符号

演出层顶栏「选歌」按钮（快捷键 `L`）的图标从购物篮换成**双音符音乐符号**，与「选歌」语义一致；`title` / `aria-label` 不变。
