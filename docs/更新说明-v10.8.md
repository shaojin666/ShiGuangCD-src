# ShiGuangCD v10.8 更新说明

本次更新是一个**全新子系统**：**全屏歌词演出层**。正在播放页播放控件旁新增「全屏」入口，点击后新界面**覆盖整个软件窗口**做歌词演出，旧歌词界面**真正停止渲染**（不是遮挡），原版界面完整保留、新旧共存。演出层自带 6 个主题（含 1 个 Three.js 3D 主题与三级降级链）、独立字体系统（可上传个人字体）、参数滑条与画质自适应。变更共涉及 **25 个文件**（12 个新增 + 12 个修改 + package.json 版本号 1.6.1 → 1.7.0 + 本说明）。

---

## 一、入口与新旧共存（需求核心：覆盖但不破坏）

- **入口**：正在播放页播放控件组右侧新增全屏按钮（`nowplaying.js` 的 `ensureRendered` 里构建，`.np-stage-btn`），与既有控件同一工具组、同一视觉语言。
- **覆盖**：`#fl-stage` 常驻挂在 `#app` 内（`index.html`），`z-index: 60` 铺满整个软件窗口；开关只切 `display`，**不销毁 DOM**——再次进入零重建成本。
- **旧界面真停渲**：`html.fl-active` 类 + 主心跳 `tickLoop` 的守卫（`app.js` 两处 early return）——旧歌词界面在演出层打开期间**不再参与任何逐帧计算**，不是简单盖住。这正是「停渲」与「遮挡」的区别：CPU/GPU 开销归零。
- **退出**：顶栏**最左侧向左箭头**（`#fl-back-btn`）点击回音乐库/播放页；`Esc` 同效。退碟、切到读盘场景会**强制关闭**演出层（`cd:phase` 守卫 + `forceClose`）——演出层绝不能盖住读盘仪式。

## 二、架构：行定位 + 词填充（folia 式，性能优先）

- **一次构建，帧内只写变量**：全部歌词行一次构建、绝对定位 `top:50%`，每帧只写两个 CSS 自定义属性（`--d` 行距 / `--ad` 绝对距离）做 smoothstep 插值；窗口 ±8 行外的行挂 `.fl-out`（`content-visibility` + 停更）真卸载开销。
- **词级填充**：只写当前行词 span 的 `--wp`（0~1）一个变量，`linear-gradient` + `background-clip:text`，**不重建任何文本节点**——与播放页逐字引擎同一套纪律（v10.4 起验证过）。
- **CSS 变量纪律**：JS 每帧只写 CSS 自定义属性；`transform` 的写入只有基础 `.fl-line` 规则一处（定位用），主题一律走**独立变换属性**（`translate`/`rotate`/`scale`）——这是「主题动画不互相打架」的根本，`ui-contract.test.js` 有纪律锁断言（含 mirror/prism 两个新主题）。
- **GSAP 只做一次性编排**（换行耀斑、面板入场等），**不进逐帧热路径**；常驻内存 72KB 一次性引入。

## 三、顶栏 / 小胶囊 / 播控菜单

- **顶栏**：Windows 三大金刚键 + 软件全屏键，自动隐藏、鼠标靠近才出现；**空闲时隐藏鼠标指针**（`cursor: none`，任意指针活动恢复）。
- **底部小胶囊**（左下，默认隐藏，鼠标靠近浮现）：轻点播放/暂停、**长按 200ms 拖进度**（带气泡预览，阈值内不抢播放）、滚轮音量。其余播控（上/下一曲、播放模式）合并为右下一个按钮弹菜单——演出界面不放full控件。
- **快捷键让位**：演出层打开期间播放快捷键整体让位（`app.js` 统一走 `FlStage.isOpen()` 短路），`Esc`/`F`/`T`/`Space`/`↑↓`/`←→` 各自归位。

## 四、主题体系：少而精，6 个

| 主题 | 类型 | 要点 |
| --- | --- | --- |
| 流光 Lumen | 2D | 封面色板派生光晕 + 词填充，默认主题 |
| 倾诉 Whisper | 2D | 字卡呼吸 + 译音淡入 |
| 回环 Orbit | 2D | 环形排布 + 慢公转（相位驱动） |
| 群唱 Chorus | 2D | 对唱左右分列 + 背景人声墙（GSAP 编排） |
| 凝彩 Prism | 2D | 玻璃棱镜双向色散 + 旋转 conic 光锥 |
| 镜台 Mirror | 3D | Three.js 点云星海 + 极坐标网格地平线 |

- **主题契约**：`{id, name, desc, type, icon, params, mount(ctx)}`，`mount` 返回 handle（`{mode, onLine, onLyrics, onParam, frame, dispose}`）。ctx 注入舞台层与工具，主题零全局依赖。
- **参数滑条**：每个主题声明自己的参数（镜台粒子密度 0.4–2.0×、凝彩色散强度 0–1.6px 与玻璃光泽 0–1），舞台级变量 `--fl-p-<key>` 是**唯一真相源**，滑条改动即时持久化到 `settings.flParams`（`{主题id: {key: 值}}`，自由合并零 schema 风险）。
- **封面色板**：主界面既有的取色结果直接复用（无 canvas 环境安全降级）。

## 五、镜台三级降级链 + 画质自适应（任何机器都能演出）

```
hasWebGL() 预探 ──否──▶ 不下载 three.js（省 608KB，零上下文错误噪音）
      │是
      ▼
three.js 点云（GL） ──失败──▶ Canvas2D 星云 ──失败──▶ 纯 CSS（--fl-mirror-ripple）
```

- **GL 分支**：ShaderMaterial 点云（呼吸 / 低频外扩 / 换行涟漪，顶点着色器内完成，CPU 只传一个 uTime）+ 极坐标网格地平线 LineSegments；相机 sin 摇摆。
- **画质自适应**：启动档位（`navigator.hardwareConcurrency` / 屏幕像素面积 / DPR 推定 高/中/低：4600/2400/1000 粒子）+ FPS 滑动窗口升降档（<42fps 持续 2.5s 降档，>57fps 持续 6s 升档，每 0.5s 评估）；**只调 `setDrawRange` 与像素比，不重建场景**；用户密度参数作乘数。
- **生命周期**：dispose 全套释放（事件监听 / 几何 / 材质 / `renderer.dispose` + `forceContextLoss` 防上下文配额耗尽 / `canvas.remove()`）；异步挂载有**代次守卫**（`mountGen`）——切换主题途中迟到的手柄自行销毁，不篡位、不留画布。

## 六、字体系统（演出层与主界面完全独立）

- **系统字体**：canvas 宽度法（探针串带中文，纯 ASCII 分不出中文字体）+ `document.fonts.check` 双保险探测，探测命中的才出现在下拉里。
- **上传个人字体**：ttf/otf/woff/woff2，≤32MB（中文字体常见 8–15MB），**魔数校验**（`00 01 00 00`/`true`/`OTTO`/`wOFF`/`wOF2`，dataURL 的 MIME 撒谎时听魔数），存 `userData/fonts/`，容量 24 个上限；清单原子写（tmp + rename），幽灵条目（文件被外部删掉）自动清理；同名同内容重复上传去重。
- **应用**：自定义字体经 `fl:read-font` 拿 dataURL 注入 `@font-face`（`<style data-fl-font>`，CSP 放行 `style-src 'unsafe-inline'` + `font-src data:`）；**用户选择永远排在默认链前面**（拼写变异的字体名后面还有 MiSans/PingFang 兜底，摔不坏）；内部族名 `FlFont-<id>` 与用户显示名解耦（两个文件都叫「思源黑体」也不撞名）。
- **入口**：设置面板「全屏歌词」区（主题 / 字号 / 译音 / 字体 + 上传删除），与演出层左上角主题面板同源同键。

## 七、测试与实测

- **`tests/fl-stage.test.js`**（新增，约 300 断言）：jsdom 全链路——外壳/停渲守卫/行定位/词填充/快捷键让位/主题面板/胶囊菜单/三大主题参数（GSAP 编排）/ **镜台三级降级每一分支**（含 FPS 升降档、drawRange 调档、dispose 释放、代次守卫）/ **字体系统全流程**。
- **`tests/fl-fonts.test.js`**（新增）：主进程字体仓库真实文件系统测试——魔数/去重/上限/原子写/幽灵清理。
- **`tests/ui-contract.test.js`**（扩充至 110 断言）：架构纪律锁——单写入/禁 transform/懒加载/白名单/CSP/降级分支。
- **真浏览器验证**（Xvfb + SwiftShader 拿真 GL）：
  - 场景 A：真 three.js 点云 28fps（软件渲染下限达标；真机 GPU 远高于此）、3 轮反复挂载画布零累积、零页面错误；
  - 场景 B/C：桩强制降级到 2D（60.2fps）/ 纯 CSS，**GL 不可用时 three.min.js 零请求**（预探优化的断言）；
  - 场景 D：凝彩色散/光锥/面板/滑条全绿；
  - M4：**上传真实 DejaVuSerif-Bold.ttf（356KB）端到端**——魔数过检 → dataURL 注入 → `document.fonts` 真加载（status=loaded）→ 演出层 computed font-family 真生效 → 删除回退默认链，全程零页面错误。
- **全量回归**：28 个套件全部通过（1 个因缺可选依赖跳过，与既有口径一致）。

### 实测抓到并修掉的坑（都有回归断言）

1. **画布泄漏**：GL 分支先 append 画布再建 renderer，失败尝试的画布留在 fx 层 → renderer 失败即 `canvas.remove()`，dispose 同样摘除。
2. **异步挂载竞态**：快速切主题时迟到 resolve 的手柄篡位 + 画布累积 → `mountGen` 代次守卫。
3. **three.js 降级噪音**：桩环境下 three.js 的 WebGLRenderer 往控制台倒错误 → `hasWebGL()` 预探，不可用连 three.js 都不下载。
4. **CSS 降级模式每帧写变量** → 变化 >0.004 才写（衰减到 0 后彻底停写）。
5. **CSP 探针实测**：`<style>` 注入被 `style-src 'self'` 拒（sheet 为 null，`insertRule` 也救不回来）→ 放行 `'unsafe-inline'`（script-src 保持严格）。
