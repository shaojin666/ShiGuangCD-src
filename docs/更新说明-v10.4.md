# ShiGuangCD v10.4 更新说明

本次更新对应用户反馈的 **8 项需求**：专辑介绍/歌手介绍元数据、专辑详情页（一镜到底）、CoverFlow 三大交互改造、歌词自动获取与自动应用、退碟清空播放界面。变更共涉及 **16 个文件**（13 个源码 + 3 个测试，其中 `renderer/js/album.js`、`tests/v10.4.test.js` 为新增）。

---

## 需求 1：元数据新增专辑介绍和歌手介绍

**抓取侧**（在线获取）：

- `main/metadata/netease.js`：新增 `fetchAlbumIntro` / `fetchArtistIntro`。专辑简介取专辑详情的 `description`；歌手简介需再问一次 `/api/v1/artist`（专辑接口本身不含歌手简介），取首位艺人的 `briefDesc`。
- `main/metadata/fetch.js`：抓取流程接入两个简介字段，**只补空值不覆盖**（`fillMissing`，与歌词/曲目同语义——用户手动改过的内容不会被联网抓取冲掉）。
- `main/metadata/schema.js`：`albumIntro` / `artistIntro` 进入白名单（透传 + 长度截断），落盘字段就齐全了。

**编辑侧**（手动修改）：

- `renderer/js/edit.js` + `renderer/css/panels.css`：编辑面板新增「专辑介绍 / 歌手介绍」两个多行输入框，保存时写回元数据。

## 需求 2：音乐库点击专辑进入详情页（一镜到底）

新增 `renderer/js/album.js`（531 行）+ `renderer/css/pages.css` 专辑页整套样式 + `renderer/index.html` 挂载 `#overlay-album`。

**进入方式统一**：原版网格卡片点击（`library.js:76`）与 CoverFlow 封面点击（`library.js:634`）走同一个 `Album.open(meta, node)`。

**设计语言 = 一镜到底**：

- **FLIP 入场**：记录被点卡片在屏幕上的真实矩形，专辑图以非线性缓动 `cubic-bezier(0.22, 1, 0.36, 1)` 从卡片原位缩放平移到详情页左侧，Esc 关闭时原路飞回；
- **背景**：canvas 28×28 降采样 → 16 级量化桶统计封面主色（跳过过暗/过淡像素），dominant + mean 两色做径向渐变；取色失败静默退化为封面高斯模糊 + 暗色 scrim。依赖 `main/index.js` 给 cover 协议加的 `Access-Control-Allow-Origin: '*'` 头（canvas 跨域读取的前提）；
- **布局**：专辑图 3D 倾斜置于界面左侧（CoverFlow 里进入时初始位置更偏右），右侧歌曲列表可点播；列表上方大字专辑名（过长先两行截断，仍放不下走无缝 marquee 滚动）；底部自然升起胶囊含「专辑 / 曲目」两个选项，曲目在右且默认选中；
- **Tab 切换不重建页面**：切到「专辑」时同一批元素位移——专辑图移到右侧并偏左，左侧显示专辑介绍，专辑名移到介绍上方。外层 `.al-art-slot` 管 Tab 位移、内层 `.al-art` 管 FLIP 入场，两层 transform 各司其职；
- **窗口 resize**：`app.js` resize 防抖回调同时联动 `Library.onResize()`（CoverFlow 重算居中）与 `Album.refitTitle()`（标题静态↔滚动重排）。

**点歌换碟续播**：详情页点歌走 `App.requestDiscTrack(meta, n)`——当前碟正是目标碟直接播；没放碟/在读碟中/是别的碟 → `App.needDisc` 携带 `{sig, meta, track}` 并提示「读取完成后将自动播放第 N 首」，换碟落地时 `onMetadata` 直接 `playTrack(target)`（显式点歌无视 `autoPlay` 设置）。

## 需求 3/4/5/6：CoverFlow 交互重写

`renderer/css/pages.css` CoverFlow 段落整段重写 + `renderer/js/library.js` 三处逻辑改动：

- **transform 驱动替代 overflow 滚动**：整行 `.lib-flow-row` translate3d 平移使焦点项中心永远对视口中线——专辑再少也能**正向居中**（需求 4，旧实现靠 scroll 留白，专辑少时焦点贴边）；
- **鼠标拖动**（需求 3）：Pointer Events + `setPointerCapture`，DOMMatrixReadOnly 读实时位移换算 focus 小数（拖动跟手、几何连续），`flow-dragging` class 关掉过渡，松口平滑归位后按最近项对齐选中；
- **滚轮 / 键盘直接选中并居中**（需求 4）：左右方向键、滚轮步进 focus 到目标项，动画结束后焦点项必然居中；
- **专辑名顶部显示**（需求 5）：中上方 26px 大字，居中；放不下时无缝 marquee（两份等宽文本 + 克隆间距补偿，`translateX(calc(-50% - 1.6em))` 才是真正无缝循环）；
- **封面放大 + 播放按钮**（需求 6）：封面 236px（原 224，全屏 316/300），选中项下方悬浮玻璃胶囊播放按钮，点击从第一首播放；当前碟高亮描边。

> `--pos` 符号约定已对照 v10.3 原版逐帧验证：右侧为正 + `rotateY(pos * -58deg)` = 右项右边缘朝前，观感与原版一致。

## 需求 7：歌词自动获取 + 自动应用（两个根因修复）

**根因 A ——「歌词不主动获取」**：缓存命中路径完全不联网。修复（`main/cd/cd-service.js`）：缓存命中但存在缺歌词的轨时，`_fillLyricsBackground` 后台补抓（fire-and-forget 不阻塞就绪）——用缓存专辑名搜网易云选碟 → 按本碟碟号 `tracksOfDisc` 建 number→songId 映射 → 复用 `attachLyrics` 降级链，**只补缺歌词的轨**，不整体重抓（避免覆盖用户手动编辑）。`main/metadata/fetch.js` 新增 `fetchLyricsOnly` 支撑这条路径。

**根因 B ——「获取到歌词不主动应用，要手动点保存」**：`NowPlaying.setLyrics` 的 `lastLyricsKey` 同键保护会误伤「缓存命中先渲染过 → 补抓完成再推同键」场景。修复（`renderer/js/app.js`）：`onMetadata` 对 `ev.fromCache !== true` 的推送强制刷新歌词视图——覆盖抓取完成、重新获取、缓存补抓三条路径。

## 需求 8：退碟后播放界面不再显示上张碟信息

- `renderer/js/app.js`：`onPhase` idle/eject 分支清空 `App.state.metadata/signature/toc/trackCount`、`App.needDisc`，收起放碟提示；
- `renderer/js/nowplaying.js`：新增 `reset()`——标题/艺人/专辑行/曲目行全部复位，曲目列表显示「尚未读取到曲目信息」，歌词区显示「等待光盘」占位，播放态归 stopped。
